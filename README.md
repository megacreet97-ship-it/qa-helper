# QA Helper

QA Helper — test data generator toolkit for QA engineers.

## Запуск

```bash
npm install
npm run db:push   # создать таблицы
npm run dev       # разработка
npm run build && npm start   # продакшн
```

Для генерации аудио и видео нужен `ffmpeg` в `PATH`.

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `DATABASE_URL` | да | Строка подключения к PostgreSQL |
| `SESSION_SECRET` | в продакшне | Секрет для подписи сессий. Без него сервер не стартует при `NODE_ENV=production` |
| `ADMIN_PASSWORD` | для первого запуска | Пароль пользователя `admin`. Если не задан и админа в базе нет, админ не создаётся |
| `TRUST_PROXY` | за прокси | Поставьте `1`, если сервер стоит за Caddy/nginx: тогда лимиты запросов видят реальный IP клиента, а cookie получают флаг `Secure` при HTTPS |
| `PORT` | нет | Порт HTTP-сервера, по умолчанию `5000` |

## Ограничения

- `/api/admin/login` — 10 неудачных попыток за 15 минут с одного IP.
- `/api/generate/*` — 60 запросов в минуту; ffmpeg — 2 задачи одновременно, до 8 в очереди, остальные получают `503`.
- `/api/fetch-url` — 20 запросов в минуту, только публичные `http(s)`-адреса (внутренние сети, localhost и metadata-адреса облаков заблокированы), ответ до 5 МБ.
